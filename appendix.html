附表 3χ² 分布表

χ²α(n) 为自由度 n 的 χ² 分布分位数。左半列为下侧分位数（P{χ² ≤ x} = α），右半列为上侧分位数（P{χ² > x} = α）。

n > 40 的近似公式

当自由度 n 较大时，可用近似 χ²α(n) ≈ ½ ( zα + √(2n − 1) )²，其中 zα 为标准正态分布的上侧 α 分位数。

附表 4F 分布表

表中数值为 Fα(n₁, n₂)，满足 P{F ≤ Fα(n₁, n₂)} = 1 − α。行 = n₂（分母自由度），列 = n₁（分子自由度）。自由度覆盖 1~30、40、60、120 及 ∞。
